# MatterMatch v0.2.1

First GitHub release checkpoint: three release blockers fixed, regression tests
added, and a documented pause/resume point. This is an early-stage local CLI;
the known limitations below remain open.

## Fixes

- **Input safety:** scan output cannot alias the inventory or a source image.
  Direct/resolved paths, symlinks, and existing hard links are checked before
  decoding or artifact writes. Collisions return status 2; unverifiable paths
  return status 3. Shell redirection onto an input is still unsafe.
- **Retry correctness:** incidental overlap between the boxes of separate,
  rotated, same-payload QRs no longer causes one symbol to be discarded.
- **Verification interoperability:** optional `chip-tool` checks correctly
  distinguish QR flow 1 from its manual-code representation, Custom flow 2.

The source archive includes the handoff, development/release instructions,
design, changelog, and lockfile. Runtime dependencies and the CSV/JSONL schemas
are unchanged.

## Validation

- Linux CPython 3.10.20 and 3.12.13: **149 tests passed** on each.
- Declared minimum runtime dependencies: **147 passed, 2 skipped** because
  zxing-cpp 2.2.0 lacks the test fixture's barcode-generation API.
- Fresh wheel/source builds and `twine check`: passed.
- Clean wheel and sdist installations: **149 tests passed** in each.
- Installed-wheel synthetic native scan: CSV/JSONL, retries, artifacts,
  collision protection, version consistency, and local flow-1 verification passed.
- Independent review found no release-blocking issues in the three fixes.

No live installed `chip-tool`, physical commissioning, or macOS/Windows
validation was performed. Flow regressions use independent synthetic vectors
and realistic logs referenced to CHIP v1.4.0.0.

## Known limitations

1. The tested native decoder can silently saturate at 255 detections. The
   Python-side 512 retry cap is not a completeness guarantee. Use strict expected
   counts when known and avoid relying on dense scans as exhaustive inventories.
2. Scan normalization can bypass the parser's raw-text whitespace-length check;
   JSONL retains that raw text. The reproduction used an injected detection.
3. Some valid wider optional TLV integer encodings are rejected even when their
   values fit the required numeric range.
4. Comparing an existing diagnostic artifact reads that file in full. Use a
   private, trusted diagnostics directory; large pre-existing files can consume
   excessive memory.

Real inventories, images, CSV/JSONL, and verification stdout contain sensitive
commissioning material. Keep them outside the checkout. No automated CI or
cross-platform support matrix is established yet.

## Install this checkpoint

```sh
pipx install git+https://github.com/squiddity/mattermatch.git@v0.2.1
```

This pins the tag; upgrading to a later tag requires selecting that tag
explicitly. Alternatively, install the attached wheel with pipx or in a virtual
environment. No PyPI publication is part of this release.

Assets: wheel, source archive, and `SHA256SUMS`. Verify downloaded assets with
`sha256sum -c SHA256SUMS` from their directory.

Start again with the bundled `docs/HANDOFF.md`, or read it at:
https://github.com/squiddity/mattermatch/blob/v0.2.1/docs/HANDOFF.md
